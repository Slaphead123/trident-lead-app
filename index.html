Trident Lead Cards

Set up once on this phone. Your leads stay in your private lead-finder repo; this page holds no lead data.

1. Make a read-only key
  1. Open GitHub: new fine-grained token.
  2. Name it Lead Cards phone. Choose an expiry (90 days or more).
  3. Repository access: only select repositories, then lead-finder.
  4. Permissions: Repository, Contents: Read-only. Nothing else.
  5. Generate and copy it.
2. Paste it here

The key is kept on this phone only. If it expires, open this page with ?reset on the end and paste a new one.

3. Add to Home Screen

iPhone: Safari, Share, Add to Home Screen. Android: Chrome menu, Install app. It then opens full screen with its own icon.
